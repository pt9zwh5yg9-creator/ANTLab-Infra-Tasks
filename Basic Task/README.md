# 大模型推理优化基础阶段考核

## 项目介绍

本任务面向大模型推理部署与优化方向的同学。请为一个不超过 10 人的小公司或工作室搭建本地 GPU 推理服务，支持办公文档处理和辅助编程，并开发性能测试、文件存储、前端展示与服务恢复功能。结合实际工作负载，选择一项或多项性能指标进行优化，用原始数据和书面报告呈现优化过程与效果。

任务周期为一周，具体截止日期和时间以任务发布通知为准。请在截止时间前将完成的项目推送至自己的 GitHub 仓库，并提交仓库链接及最终提交的 commit SHA。

## 任务入口

- [任务介绍](任务介绍.md)：场景、环境、功能、测试和优化要求。
- [提交标准](提交标准.md)：提交内容、GitHub 提交流程及验收依据。
- [测试提示词](提示词与输入文档/测试提示词.md)：纯提示词任务和关联文件任务。
- [报告模板](报告模板/基础阶段考核报告模板.md)：书面报告的建议结构。
- [开发区域](development/README.md)：源码、配置、测试、结果和报告的位置。

## 开展方式

1. Fork 本仓库，在自己的仓库中开展开发。
2. 使用 WSL 和支持 CUDA 的独立显卡部署 llama.cpp／llama-server，并选择适合硬件与任务的 GGUF 模型。
3. 使用 AI 辅助编码工具完成开发，对关键代码、测试方法及结果进行核验。
4. 在 `development/` 中完成系统开发，运行规定输入的功能测试、单并发与多并发测试、异常恢复测试。
5. 保存基线和优化数据，完成书面报告，并通过 GitHub 提交最终作品。
