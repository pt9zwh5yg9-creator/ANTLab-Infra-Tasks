# 测试结果

按运行编号保存结果，例如：

```text
results/
├─ baseline-c1-run01/
│  ├─ config.json
│  ├─ requests.jsonl
│  ├─ summary.json
│  └─ outputs/
├─ optimized-c4-run01/
└─ recovery-run01/
```

文件格式可自行选择，建议字段包括：

- 运行编号、配置版本、Git commit、硬件与模型信息、测试起止时间。
- 请求 ID、提示词编号、文档校验值、实际输入与输出 token 数。
- 提交、首次有效生成内容、结束的时间点，以及可采集的服务端处理时间。
- 输出内容或输出文件路径、状态、错误信息和重试关联信息。
- 逐请求指标、汇总口径、成功率及中位数/P95。
- 容量测试记录 KV 类型、配置总容量、各 slot 可用容量、实测可用容量（单位均为 token）、共享或分槽方式、并发条件及验证边界。
- GPU 监控、加载日志、异常恢复时间线、优化前后配置差异。

正式测试数据与恢复日志提交到 GitHub。临时模型、环境、编译文件和 KV 快照放在被 `.gitignore` 管理的位置。报告用运行编号和相对路径引用这里的数据。
