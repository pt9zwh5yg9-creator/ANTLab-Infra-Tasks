# 配置

保存服务、模型、测试负载、基线及优化配置。每次正式测试绑定一个可追溯的配置版本。

建议记录模型路径或别名、模型校验值、llama.cpp 版本、上下文容量、输出上限、GPU 层与 KV 位置、主机 prompt cache 状态、KV 精度、Flash Attention、批处理参数、slot 数和采样参数。

负载配置包含提示词编号、文件版本、输入组织方式、并发数、请求顺序或随机种子、重复次数和缓存处理方式。精简输入保存在固定位置，并记录截取规则。

开展 KV 容量测试时，记录配置总容量、各 slot 可用容量（单位为 token）、共享池或分槽方式，以及用于容量验证的上下文长度与并发设置。

密钥通过环境变量提供，仓库保留可填写的示例配置。
