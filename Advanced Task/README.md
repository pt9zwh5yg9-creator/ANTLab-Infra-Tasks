# 大模型推理优化进阶阶段考核

## 项目介绍

本阶段采用开放式推理优化开发题目。同学们结合硬件条件、应用需求和兴趣，自行调研问题、确定选题、设计实现，并通过测试验证优化效果。可以扩展基础阶段的系统，也可以使用和改造开源项目。

选择一个有实际应用价值的问题，明确自己的开发内容，记录基线、优化过程、性能收益与资源和输出效果变化。源码、配置、原始数据和书面报告通过自己的 GitHub 仓库提交。

任务周期为一周，具体截止日期和时间以发布通知为准。请在截止时间前完成推送，提交仓库链接、分支和最终 commit SHA。

## 任务入口

- [任务介绍](任务介绍.md)：开放选题、环境、开发与验证要求。
- [选题参考](选题参考/README.md)：KV 缓存管理、请求优先级调度及自主探索。
- [参考测试](参考测试（仅作参考）/README.md)：场景、提示词、输入材料与请求序列。
- [提交标准](提交标准.md)：GitHub 提交内容与验收依据。
- [报告模板](报告模板/进阶阶段考核报告模板.md)：问题、实现、测试和结果的组织方式。
- [开发区域](development/README.md)：源码、配置、测试、结果和报告。

## 开展方式

1. Fork 本仓库，确定应用场景和拟解决的问题。
2. 在 `development/` 中自行组织项目，重点提交自己实现或修改的部分，保留开发过程。
3. 定义基线、指标和固定负载，设计能够检验方案的测试。
4. 保存原始记录，展示关键状态与优化效果，完成书面报告；可根据项目需要开发前端。
5. 在截止时间前提交完成的 GitHub 项目。

三条参考方向可以组合、扩展，也可以采用其他选题。参考素材可作为测试起点；自行设计的负载需说明来源、组织方式及判定依据。

`development/` 的内部结构由同学们自行设计。源码可以围绕自己的开发内容提交，依赖项目提供来源、版本和获取方式；配置、测试、数据和报告的位置在开发说明中列出。
