# 开发区域

在本目录完成自己的进阶项目。可以扩展基础阶段系统，也可以使用和改造开源项目。语言、框架、模块划分和目录结构由同学们根据选题自行设计，按项目需要创建文件和子目录。

## 源码组织与提交

重点提交自己实现或修改的部分，可以只提交自编模块、适配代码、引擎补丁及相关配置和测试。依赖的开源项目完整源码可通过项目链接和明确的版本或 commit 获取。

改造开源项目时，说明原项目的来源、基线版本和自己的修改范围。修改可以通过本仓库中的代码、可应用的补丁，或对应 fork 仓库的 commit／差异链接呈现，并提供获取依赖、应用修改和运行项目的方法。

配置、测试、原始数据和书面报告的位置自行安排，在本文件中提供入口。模型、构建产物和大型缓存数据按运行说明获取或生成；仓库保留复现信息和可复查的样例。

## 开发说明

请在开发过程中将本文件更新为项目入口，包含：

1. 选题、应用场景、问题与优化目标。
2. 自己实现或修改的内容，以及对应代码、补丁或 fork 差异的位置。
3. 系统结构、目录说明、环境、依赖项目与模型的来源及版本。
4. 获取依赖、应用修改、启动、测试与异常恢复的方法；有前端时提供访问入口。
5. 基线与优化配置、固定负载及结果复现方法。
6. 原始记录、优化结果、书面报告及配图的位置。

保留自己的 Git 开发历史，使功能实现、修复和优化过程便于查看。
