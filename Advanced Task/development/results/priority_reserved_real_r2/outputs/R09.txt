```python
import smtplib

def check_email():
    try:
        server = smtplib.SMTP('smtp.example.com', 587)
        server.starttls()
        server.login('your_email@example.com', 'your_password')
        print("Email account is working properly.")
    except Exception as e:
        print(f"Email account check failed: {e}")

check_email()
```

请根据实际情况调整邮箱服务器和登录信息。
