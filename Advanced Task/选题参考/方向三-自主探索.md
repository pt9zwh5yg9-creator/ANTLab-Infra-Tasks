# 方向三：自主探索

围绕 llama.cpp 推理部署与优化，自行调研并选择有实际应用价值的问题，也可以组合缓存与调度等方向。

可以从已观察到的瓶颈、开源项目中的功能缺口、具体使用场景或资源限制出发。潜在切入点包括请求长度预测与资源分配、批处理控制、推理过程观测、长上下文处理或其他优化。

在选题中说明：

1. 谁会使用该功能，当前问题是什么。
2. 有哪些现成能力，准备开发或修改哪些模块。
3. 目标指标和功能判定依据是什么。
4. 如何构造基线与固定负载。
5. 如何观察资源代价、输出效果和异常处理。

形成可运行的实现，保存调研依据、版本与关键改动。用测试和演示说明方案适用的场景、实际效果和后续改进，按共同提交标准交付。
